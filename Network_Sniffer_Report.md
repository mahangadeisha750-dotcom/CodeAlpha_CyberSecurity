Basic Network Sniffer Report

Project 3: Network Sniffer

Internship: CodeAlpha Cyber Security
Created by: Isha Suhas Mahangade

1. Introduction

A Network Sniffer is a tool used to observe network traffic and understand how data travels through a network.

2. Objective

To understand basic network communication and learn how Python sockets are used for network monitoring.

3. Technologies Used

- Python
- Socket Library
- Cxxdroid / Python Environment

4. Working

1. Import the Python socket library.
2. Create a network socket.
3. Attempt to access network packets.
4. Display a message when the sniffer starts.
5. Handle permission and network errors.

5. Applications

- Network monitoring
- Network troubleshooting
- Understanding network communication
- Cybersecurity learning

6. Safety

Network monitoring should only be performed on devices and networks where permission is available.

7. Conclusion

This project helped me understand the basics of network monitoring, Python sockets and network communication.
